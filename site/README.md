# site/ — the YBMA parent website

An implementation of the locked identity. It invents no visual language: colour, type, spacing,
shape, components and logo geometry all come from `identity/`. If something looks wrong on the site
and the cause is a brand value, the fix belongs in `identity/`, not here.

**Status:** content, positioning and imagery passes complete (Sessions 29 to 31). Not launched. See
`CONTENT-CHECKLIST.md` for what is still missing and what was removed from the public site.

## Build and run

```bash
node site/build.js                                   # renders the seven pages + assets into site/dist/
python3 -m http.server 8767 --directory site/dist    # then open http://localhost:8767
```

No dependencies, no framework, no build tooling beyond Node. Not React: plain HTML, CSS and one small
script, generated from `src/`. The build prints every unresolved placeholder and the em-dash count.

## Deploying on Vercel

`vercel.json` at the repository root configures everything: build command `node site/build.js`,
output directory `site/dist`, no install step, clean URLs with trailing slashes, cache headers for
`/assets/`. Import the repository in Vercel and deploy; no dashboard settings are needed. `site/dist/`
is git-ignored and rebuilt on every deploy. Set the production domain to `ybmahq.com` in Vercel; the
site already uses it for canonical and Open Graph URLs.

## Easter eggs (six)

All in `src/site.js` (one IIFE after the menu) and the tail of `src/site.css`. Each is quiet, uses the
system's own motion (a cut or a quarter-turn), respects `prefers-reduced-motion`, and ignores keys
typed into inputs.

| # | Trigger | What happens |
|---|---|---|
| 1 | Konami code (up up down down left right left right b a) | The header symbol makes one quarter-turn and settles back |
| 2 | Type `ybma` anywhere on a page | Four cuts: the wordmark letters disappear and are restored one at a time |
| 3 | Click the header symbol five times within two seconds | A small ink toast: "Two stones, one joint." (the symbol's own description) |
| 4 | Press `.` | Toggles the layout grid overlay (12 columns, 24 gutter, 32 margin, 1240 max, 8 baseline) |
| 5 | Open the browser console | The mark drawn in indigo and a note for people who build things, pointing at hello@ybmahq.com |
| 6 | Visit a page that does not exist | The 404 page: "Nothing here. Everything else is." |

None of them add copy to the pages, change the identity, or run until triggered.

## Structure

```
site/
  build.js                 renders pages, copies assets, reports placeholders
  src/
    content.js             shared facts, placeholders and photo records; edit content here first
    layout.js              document head, header, footer
    parts.js               photograph slot (one image in the identity's crop; swappable file)
    photos/                temporary stock photography + SOURCES.md (credits and licences)
    pages/{home,company,technology,contact,privacy,terms,notfound}.js
    site.css               page layout only — no colours, no type scale of its own
    site.js                the mobile menu and the six easter eggs; the only script on the site
  dist/                    generated by the build — the only thing deployed; git-ignored
```

## Copy rules (binding)

Public copy states what YBMA is and does; internal strategy, structure, hypotheses and plans stay
in the state file. No em dashes anywhere in website copy (the build counts them and must print 0).
Nothing invented: no clients, revenue, statistics, partnerships, products, subsidiaries, future
businesses, locations, awards or testimonials. No geographic positioning: the country is not
named in copy, metadata, alt text or the footer unless a specific sentence genuinely needs it. YBMA Technology is described as a horizontal capability inside an operating
company: practical technology built around how a business works. No industry, workflow or software
category is named as its market.

## Two documented deviations

Both are flagged in the deliverables for approval rather than silently changed in `identity/`.

1. **Hero order on small screens.** `WEB_FOUNDATION.md` says the hero stacks "image first". A
   portrait image first pushed the hero statement below the fold on a phone, and the hero's job is
   to say what YBMA is. Text leads; the image follows immediately, keeping its one round corner.
2. **Label colour.** `tokens.css` assigns the label role to "ink or grey-500". Measured, grey-500 on
   chalk is 4.01:1 — below WCAG AA (4.5) at label sizes, while the guideline claims AA throughout.
   The site uses grey-700 (8.06:1). The token file is unchanged; the guidance needs a decision.

## Identity rules the site keeps

One curved end, one square end · one round thing per composition · one field per view, sections
alternating chalk and indigo · indigo and ink never touch · emphasis by scale, field, curve, weight
and photography — never by a hue · motion is a cut or a quarter-turn · sentence-case headlines,
labels the only caps · no accent colour, no gradients, no patterns.
