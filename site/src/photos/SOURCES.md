# Website photography — sources

Temporary imagery until YBMA's own documentary photography exists. Every image is licensed for
commercial use without attribution under the Pexels License (https://www.pexels.com/license/);
credit is recorded here regardless. Each file is loaded by one slot in `src/parts.js`; replacing a
file (same name, any ratio) swaps the photograph without touching the layout.

Brief applied (Session 31): technology applied to real work in the context of modern African
businesses. Contemporary, professional, real, understated. No factories, machinery, warehouses or
inventory; no server rooms or coding clichés; no plain-backdrop stock poses; natural colour.
