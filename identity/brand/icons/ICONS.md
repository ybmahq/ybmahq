# YBMA icons · Session 27

Drawn the way the letters are: **24-unit grid · 2-unit stroke · round joins · square ends · arcs of
radius 3** (the 16 : 21 module at 24 px) · ideally one curve per icon · **ink or white only** (indigo
for a selected state in product UI, never for the icon itself). No third-party icon library.

Starting set (12): arrow · check · document · handover · building · plant · chart · code · menu ·
close · external · mail. Individual files `ybma-icon-<name>.svg`; sprite `ybma-icons-sprite.svg`
(`<use href="#ybma-icon-arrow">`). Use with `stroke="currentColor"` in the product so the icon takes
the text colour. New icons are drawn on these rules as the product needs them.
