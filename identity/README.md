## Masters vs exports
- **Masters** are the two files in `logo/master/`. Everything else under `logo/` is an **export** and is
  regenerated by `node identity/logo/master/export.js`. **Never edit an export.** If a file is wrong,
  fix the geometry or the script and re-export.
- `brand/colour/tokens.css` is the master for colour, type and layout values; `tokens.json` mirrors it.

## Naming convention
`ybma-<asset>-<colour>[-<size>].<ext>`
- **asset:** `wordmark` · `symbol` · `lockup-horizontal` · `lockup-stacked`
- **colour:** `ink` (#151412) · `indigo` (#1F2C6B) · `white` (reversed; lives in `logo/reversed/`)
- **size** (PNG only): `h<px>` = height for wordmark and lockups · `<px>` = side for the symbol
- **ext:** `svg` (web, vector) · `pdf` (print, vector, one page sized to the artwork) · `png` (transparent, RGBA)
- Icons: `ybma-icon-<name>.svg`. Tokens: `tokens.css` / `tokens.json`. Never rename an export.

## Which file to use
| Use | File |
|---|---|
| Website, app, documents on screen | `logo/**/*.svg` |
| Print, signage, embroidery, stamps — anything sent to a vendor | `logo/**/*.pdf` (vector; specify the colour by Pantone or black in the order) |
| Slides, email signatures, social profiles | `logo/**/*-h256.png` or `-256.png`; `1024` for large placements |
| Dark or indigo grounds | `logo/reversed/*-white.*` |
| Rendering the logo in code | `logo/master/ybma-logo.js` — `YBMA.wordmarkSVG()`, `YBMA.symbolSVG()`, `YBMA.lockupHorizontal()`, `YBMA.lockupStacked()` |

## Locked geometry (do not change)
Wordmark: cap 100 · stroke 16 · radius 21 (29 outer / 13 inner) · tracking 12 · Y 58 · B 63 · M 100 ·
A 58 · 315 × 100 · M and A crowns overshoot 1.2 · square terminals. Symbol: 120 square · entry 18 ·
descent dx/dy 0.5625 · turn 86 · joint 11 · corner sheared across the band. Clear space 32 (wordmark,
lockups) / 24 (symbol). Minimum sizes 20 px · 16 px · 24 px (6 / 5 / 7 mm).
